1. Introduction

The DMCMES Smart Attendance System is built for Don Marcelo C. Marty Elementary School, Sta. Cruz, Zambales. It uses face recognition to mark student attendance in under one second and can notify parents or guardians by email when an address is linked to the student's account.

The system provides separate access for administrators, teachers, and students. Administrators manage accounts, cameras, and attendance records; teachers monitor class sessions and student arrivals. If a face scan cannot be used, attendance can also be recorded manually or with a QR code. Email alerts can include the attendance event, time, and scan location.

4. Getting Started

4.0 Accessing the System

To access the DMCMES Smart Attendance System, visit https://smartattendacedmcmes.freehosting.dev/ in your browser. From there, users can either sign in with an existing account or create a new one if they are not yet registered.

1
Open the system in your browser and land on the public homepage.
2
Use the Sign In button to access the dashboard if you already have an account.
3
If you are a new user, click Register and complete the form with your personal information and role details.
4
After registration, the account remains pending approval until an administrator approves it.
5
Once approved, the user is redirected to the correct dashboard based on their role: Student, Teacher, or Administrator.
💡
Role Access: Each account is assigned a role, and after login, the user sees only the tools and pages relevant to that role.

4.1 Registration

1
Go to the login page and click Register here, or click Register in the landing page navbar.
2
Fill in your Full Name, Email Address, select your Role, and enter role-specific fields (Student ID / Employee ID).
3
Enter a Password (min. 8 chars). A live strength bar shows Weak / Good / Strong as you type.
4
Enter Confirm Password. A live indicator shows ✅ Passwords match or ✗ Passwords do not match. The form won't submit if they don't match.
5
Accept the Terms and Conditions and click Create Account.

6.2 Class Sessions

Starting a Session

1
Fill in Subject, Section, select a Camera, and choose Type (In or Out).
2
Optionally set a Schedule time range.
3
Click ▶ Start. The session becomes live.

Live Face Recognition Camera

1
Open an active session and click the 📷 Camera button.
2
The face recognition camera opens — students stand in front and the system auto-detects and records attendance.
3
A confirmation shows the student's name when recognized.

Stopping a Session

Click Stop Session — all records are saved and the session is marked as Ended.

6.3 Manual Attendance Entry

For situations where face recognition is unavailable:

1
Open the active session.
2
Find the student and click Mark Manually.
3
Attendance is recorded with current timestamp and labeled "Manual".

Session History

All past sessions appear in the Session History table with Subject, Section, Type, Camera, Start/End time, and Status (Active / Ended).

7.2 User Management & Approvals

Go to Users in the sidebar. The page has two sections:

  • Pending Approvals — amber card at the top showing all unapproved users
  • All Users — table of all approved users

Approving a User

1
Find the user in Pending Approvals and click Approve.
2
A confirmation modal appears: "Are you sure?" with a green Approve button.
3
Confirm — the user can now log in.

Approving All Users at Once

Click ✓ Approve All in the Pending Approvals header → confirm in the modal → all pending users approved.

Denying a User

Click Deny → confirm in the modal → account is permanently deleted.

✅
Confirmation Modals: All critical actions (Approve, Deny, Delete, Approve All) show a clean "Are you sure?" modal before proceeding — no accidental actions.
⚠️
Denial is permanent. The user must re-register if denied by mistake.

Adding a User Directly (Admin-Created)

Click + Add User → fill in details → Create User. Admin-created accounts are auto-approved and can log in immediately.

Editing / Deleting Users

✏️ Edit button → update fields → Save. 🗑️ Delete button → confirm modal → user permanently removed.

8. Troubleshooting & FAQ

Common Issues

🚫 Face Not Recognized
Ensure proper front-facing lighting. Remove glasses/hats. Check camera permissions. Contact admin to re-register face.
📷 Camera Not Working
Check browser camera permissions (click camera icon in address bar). Close other apps using camera. Try refreshing.
🔒 Cannot Log In
Check email/password spelling. If yellow warning shows — wait for admin approval. Clear browser cache if needed.
📄 PDF Not Downloading
Allow pop-ups/downloads from this site in browser settings. Wait for "Generating..." to finish before clicking again.
🔑 Passwords Don't Match on Register
Watch for the live indicator below the Confirm Password field. Red = mismatch, Green = match. Form won't submit if mismatched.

FAQ

QuestionAnswer
Is facial data secure?Yes. Only mathematical descriptors are stored, not photos. Data is encrypted.
Can I use glasses?Yes, but register with and without glasses for best accuracy.
Why is my account pending?Admin hasn't approved it yet. Contact your school admin directly.
Can someone mark attendance for me?No. Face recognition ensures only you can mark your own attendance.
Can a new admin register?Yes, but they must wait for an existing approved admin to approve them first.
How accurate is face recognition?95%+ under normal lighting. Accuracy drops in dim/backlit environments.
What does "Method: System" mean?Attendance was recorded automatically by the system (face scan).
What does the green theme mean?The UI colors are aligned to the school logo — forest green + gold flame.
